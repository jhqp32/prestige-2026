## Голосование

Данные сохраняются в Supabase. Публичный ключ в клиенте предназначен для браузера. Не добавляйте в репозиторий service_role, пароли или секретные ключи.

Плановый старт: 11 ноября 2026, 00:00 МСК. Завершение: 28 ноября 2026, 00:00 МСК. Источник времени и доступности — сервер vote_stats.

Выполните database/update-candidates.sql в Supabase SQL Editor, если последние изменения состава ещё не применялись. Обновление включает все 121 варианта, сохраняет даты, голоса и права доступа и не открывает голосование.

Один голос на номинацию с каждого браузера. Ограничение использует идентификатор браузера и не является проверкой личности: другое устройство или очистка хранилища позволяет получить новый идентификатор. Результаты отдельных бюллетеней закрыты от публичного чтения.
